EventPass

Inscrições em eventos, ingressos com QR Code, check-in e pontuação após presença validada.

ReactTypeScriptNode.jsQR Code

O desafio

Organizar inscrições e controlar a presença dos participantes, reduzindo etapas manuais para os organizadores.

A solução

Área pública de eventos, inscrições e ranking, com painel protegido, check-in por QR Code e relatórios.

Arquitetura

React e TypeScript no frontend, Node.js na API, testes e verificações automatizadas no CI.

  1. React
  2. API Node.js
  3. Inscrição + check-in
  4. Validação da presença

Decisões e aprendizados

  • A pontuação é concedida somente após check-in válido.
  • A página /demo simula a jornada com dados fictícios sem alterar a produção.
  • Ingressos são acessados pelo link emitido, sem promessa de recuperação por e-mail.

Evidências documentadas

  • Demonstração pública da jornada em /demo
  • CI com lint, testes, typecheck e build
  • Capturas documentadas
