Registro pessoal · ESTUDO DE CASO

MounTrack

Aplicação de registro pessoal de medidas, sintomas e evolução, sem orientação clínica.

JavaScriptNode.jsPostgreSQLPWA

O desafio

Organizar registros pessoais com controle de acesso.

A solução

Registro manual, gráficos, exportação e exclusão de dados.

Arquitetura

PWA e API Node.js com PostgreSQL e isolamento de dados por usuário.

  1. Interface PWA
  2. API Express
  3. PostgreSQL

Principais funcionalidades

  • Registro manual de medidas e observações pessoais, com gráficos de evolução.
  • Exportação e importação de dados em JSON, exclusão de registros e da conta.
  • Interface responsiva e instalável, com painel administrativo separado.

Decisões técnicas e limitações

  • O acesso aos registros é limitado ao usuário autenticado. O painel administrativo não apresenta registros de saúde.
  • O isolamento é lógico, sem criptografia individual das colunas no banco.
  • O sistema registra informações fornecidas pelo usuário, sem diagnóstico ou recomendação clínica.

Evidências documentadas

A documentação descreve testes de integração com PostgreSQL descartável, consentimento, revogação de sessão e concorrência. Não foram executados nesta revisão.
