Calculadora Python

Calculadora desktop em Tkinter com versão web e testes de regras aritméticas.

PythonTkinterJavaScript

O desafio

Praticar lógica, validação de entrada e interfaces.

A solução

Operações aritméticas, memória, tratamento de erros e histórico na versão web.

Principais funcionalidades

  • Operações básicas, porcentagem, alternância de sinal e tratamento de erros.
  • Memória, histórico de até 20 cálculos e suporte a teclado na versão web.
  • Preservação da versão acadêmica desktop em Tkinter.

Arquitetura

Python e Tkinter na versão original, HTML, CSS e JavaScript na versão web.

  1. Python / Tkinter
  2. Lógica de cálculo
  3. JavaScript / Web

Decisões técnicas e limitações

As duas versões compartilham a lógica de operações encadeadas, mas usam formatos de precisão diferentes.

Evidências documentadas

O README registra 36 testes automatizados da versão web, incluindo divisão por zero, memória e histórico.
