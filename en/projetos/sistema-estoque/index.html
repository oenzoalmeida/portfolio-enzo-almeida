Inventory management · CASE STUDY

Sistema de Estoque

Academic Python project extended into a web version with movement history.

PythonJavaScriptFirestore

The challenge

Organize products and track incoming and outgoing stock.

The solution

Product registration, low-stock alerts, filters and movement history.

Main features

  • Product registration, filters and minimum-stock alerts.
  • Stock entries and withdrawals with movement history.
  • Dashboard metrics and CSV export.

Architecture

Original object-oriented Python version and web version with Firestore.

  1. Web interface
  2. Inventory rules
  3. Firestore

Technical decisions and limitations

The web version preserves the original Python project rules. Stock cannot become negative. The demo uses anonymous authentication and should not receive real data.

The README records 33 automated model tests, including validation, movements and metrics.
