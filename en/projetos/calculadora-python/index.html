Academic project · CASE STUDY

Calculadora Python

Tkinter desktop calculator with a web version and arithmetic rule tests.

PythonTkinterJavaScript

The challenge

Practice logic, input validation and interfaces.

The solution

Arithmetic operations, memory, error handling and history in the web version.

Main features

  • Basic operations, percentages, sign switching and error handling.
  • Memory, history of up to 20 calculations and keyboard support in the web version.
  • Preservation of the original academic Tkinter desktop version.

Architecture

Python and Tkinter in the original version, HTML, CSS and JavaScript on the web.

  1. Python / Tkinter
  2. Calculation logic
  3. JavaScript / Web

Technical decisions and limitations

Both versions share chained-operation logic but use different precision formats.

Documented evidence

The README records 36 automated web tests, including division by zero, memory and history.
