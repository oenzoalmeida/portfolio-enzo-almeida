Web application · CASE STUDY

AutoCiclo

Digital vehicle records with service history, expenses, documents and maintenance reminders.

Next.jsTypeScriptSupabasePostgreSQL

The challenge

Organize maintenance for multiple vehicles in a history that is easy to consult and update.

The solution

Multi-vehicle garage, timeline, expenses by category, private documents and printable reports.

Architecture

Next.js and TypeScript, Supabase with PostgreSQL, authentication, storage and Row Level Security.

  1. Next.js
  2. Supabase Auth
  3. PostgreSQL + RLS
  4. Private storage

Decisions and lessons learned

  • RLS isolates database records by account.
  • Installable PWA, but data still requires an internet connection.
  • The AutoCiclo Score reflects record organization, not mechanical condition.

Documented evidence

  • Migrations and RLS policies in the repository
  • Unit tests with Vitest
  • Actual screenshots of the homepage and features
