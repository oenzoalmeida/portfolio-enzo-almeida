Application security · CASE STUDY

Cofre

Case study of a credential manager with encryption and access control.

ReactTypeScriptPostgreSQLAES-GCM

The challenge

Study protected storage and access control for confidential information.

The solution

Masked credentials, optional multifactor authentication and access event logging.

Architecture

TypeScript application with PostgreSQL and authenticated server-side encryption.

  1. React / TypeScript
  2. Server / authentication
  3. PostgreSQL

Main features

  • Credential organization by project and personal area.
  • Masked secrets in the interface, controlled reveal and copy actions.
  • Optional multi-factor authentication and access event logging.

Technical decisions and limitations

  • Authenticated AES-256-GCM encryption takes place on the server, keeping the key away from the frontend.
  • Authorization distinguishes project credentials from personal records.
  • Sensitive operations are audited. Public registration remains closed.

Documented evidence

The architecture and controls are documented in the private repository. This case study is not an independent security audit or certification.
