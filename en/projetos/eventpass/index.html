EventPass

Event registration, QR-code tickets, check-in and points awarded after attendance is verified.

ReactTypeScriptNode.jsQR Code

The challenge

Organize registrations and track attendance while reducing manual steps for organizers.

The solution

Public event listings, registration and rankings, with a protected dashboard, QR-code check-in and reports.

Architecture

React and TypeScript frontend, Node.js API, automated tests and CI checks.

  1. React
  2. Node.js API
  3. Registration + check-in
  4. Attendance verification

Decisions and lessons learned

  • Points are awarded only after a valid check-in.
  • The /demo page simulates the workflow using fictional data without modifying production.
  • Tickets are accessed through their issued link, without automatic email recovery.

Documented evidence

  • Public workflow demo at /demo
  • CI with linting, tests, type checking and build
  • Documented screenshots
