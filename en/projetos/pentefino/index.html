PenteFino

Personal project for identifying document inconsistencies through processing and AI.

JavaSpring BootReactGemini

The challenge

Reduce repetitive checks in complex PDFs while retaining human review.

The solution

Workflow in development for PDF upload and validation, background processing through a persisted database queue and Gemini-assisted analysis with human review.

Architecture

Java/Spring Boot backend, React frontend and PostgreSQL, with authentication, PDF validation, asynchronous processing, failure handling and structured AI response validation. Private source code.

  1. PDF upload
  2. Spring Boot
  3. Persisted queue
  4. Gemini + human review

Decisions and lessons learned

  • AI analysis is assistive and requires human validation.
  • The persisted queue enables background document processing.
  • AI responses are validated before being presented.
  • The repository and internal details remain private.

Documented evidence

  • Private project; no validated public demo
