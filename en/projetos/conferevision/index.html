ConfereVision

Kit verification from images and video, comparing detected objects with expected quantities.

PythonDjangoOpenCVYOLOXPostgreSQL

The challenge

Help identify missing and extra items in visual checks that usually require manual review.

The solution

Users configure the expected kit contents, upload media and compare detections against expected items.

Architecture

Python and Django with PostgreSQL; server-side inference using OpenCV DNN and YOLOX-s ONNX on CPU.

  1. Image or video upload
  2. Django
  3. OpenCV + YOLOX
  4. Comparison and review

Decisions and lessons learned

  • Inference runs on the server without requiring a paid AI API.
  • Results require human interpretation because detection can produce false positives and negatives.
  • History and annotated images are isolated by user.

Documented evidence

  • Documented YOLOX-s model
  • Image and video analysis workflow
  • Computer vision tests available in the repository
