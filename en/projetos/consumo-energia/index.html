Energy consumption simulation · CASE STUDY

Consumo de Energia

Electricity consumption and cost simulator with appliance comparisons.

JavaScriptNode.jsExpressPostgreSQL

The challenge

Estimate the impact of appliances on electricity bills.

The solution

Appliance and tariff registration, consumption and cost projections, with per-user data.

Main features

  • Device registration, power, usage duration and tariff.
  • Estimated monthly consumption, cost and annual projection.
  • Consumption classification and persistence of one scenario per user.

Architecture

JavaScript web interface and Express API with PostgreSQL persistence.

  1. JavaScript interface
  2. Express API
  3. PostgreSQL

Technical decisions and limitations

Values are estimates and exclude some components of real electricity bills. The README reports temporary unavailability of demo credentials.

Documented evidence

Documentation describes calculation, security and concurrency-control tests.
