Ordering application · CASE STUDY

Dona Joana Marmitaria

Case study of an ordering application for a family food business.

React NativeExpoFastAPIMongoDB

The challenge

Organize the ordering workflow of a real business.

The solution

Catalog, cart, checkout and order tracking.

Architecture

Expo/React Native interface and FastAPI with MongoDB persistence.

  1. Expo / React Native
  2. FastAPI
  3. MongoDB

Main features

  • Meal catalog, item selection and shopping cart.
  • Checkout and order tracking.
  • Pix payment integration and transactional communication, as documented by the project.

Technical decisions and limitations

  • The mobile interface consumes a separate API, keeping business rules in the backend.
  • The API uses document storage for orders.
  • The public case study excludes customer data, credentials and real payment operations.

Documented evidence

The README describes pytest tests and application/API integration. No real transaction was executed during this review.
